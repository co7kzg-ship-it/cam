How Fieldcam works

Pairing

  1. Choose Watch here and allow the microphone prompt — it only lets the browser reveal this machine's local address so the phone can find it.
  2. Scan the QR with the phone, or type the code there.
  3. Tap Connect and allow the camera.

Remote control

Autofocus, LED, zoom and frame rate act on the phone camera. A button greys out when that camera cannot do it. Photos save on either device; Record writes a .webm here.

Shortcuts

F fullscreen · S photo · R record · L led · A focus · M sound · P pause · +/− zoom · 0 reset

If it will not connect

  • Same Wi-Fi is the reliable case, VPN or not — the video never leaves the network.
  • Different networks need your own TURN relay (Settings); the free public ones are gone.
  • Offline pairing needs no server: copy one block of text each way.
  • Settings → Run connection check reports what your network allows.
