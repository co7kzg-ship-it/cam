How Fieldcam works

Two devices, one code

  1. On the computer choose Watch here. A 4-digit code and a QR appear.
  2. On the phone scan the QR (or open the same page and type the code).
  3. Tap Connect. Allow the camera prompt. Video shows up on the computer.

What the toolbar does

  • Limit FPS — asks the phone to drop to 15 fps; kinder on battery and bandwidth.
  • Save photo here / on phone — a frame from the stream, or a full-resolution frame saved on the phone.
  • Autofocus, LED, Zoom — real remote control of the phone camera, sent over the data channel.
  • Record — writes what you see (and hear) into a .webm file on the computer.

Keyboard (monitor side)

F fullscreen · S photo · R record · L led · A autofocus · M sound · P pause · + / − zoom · 0 reset view

If it will not connect

  • Both devices on the same Wi-Fi is the easy case; mobile data usually needs a relay server.
  • The camera side must be on https — browsers block cameras otherwise.
  • Corporate/ISP filtering can block the rendezvous server. Add a TURN relay in Settings, or use Offline pairing, which needs no server at all — you copy two blocks of text between the devices.

Video and audio travel directly between the two devices. The rendezvous server only helps them find each other; it never sees the picture.
